# v0.1.0 Changelog

Status: historical release notes for the first public contract package preview.

## Theme

Initial shared TypeScript/Zod wire contracts for Opstage CE and the Node embedded Agent SDK.

## Added

- Shared Zod export and typed schemas for users, sessions, registration tokens, agents, Capsule Services, health reports, configs, actions, commands, command results, audit events, dashboard summary, system health, and system version.
- Status enums and lower-case schema aliases used by CE and SDK consumers.
- Basic contract helper exports retained for v0.1 compatibility.
- Schema validation tests and package metadata for npm-oriented consumption.

## Compatibility

- Pairs with Opstage CE `0.1.x` and `@xtrape/capsule-agent-node@0.1.x`.
- Pre-1.0 contract surface; downstream repositories should pin matching minor versions.
