# v0.2.0 Changelog

Status: historical release notes for the v0.2 Public Preview contract update.

## Theme

Keep contracts runtime-neutral and align command/action protocol details across CE, Agent SDK, and demo.

## Changed

- Removed runtime ID generation helpers (`newId`, `idPrefixes`, `IdPrefix`) from the contract package.
- Removed the `nanoid` runtime dependency; contracts now remain schema/type focused.
- Tightened command/runtime enum behavior and preserved language-neutral wire shapes.
- Documented the ID generation boundary in README and changelog notes.

## Compatibility

- Wire schemas remain compatible with v0.1 clients for the main agent/control-plane flow.
- Consumers that imported ID helpers must provide their own runtime factory.
- Pairs with the v0.2 release train across CE, Agent SDK, demo, docs, and site.
