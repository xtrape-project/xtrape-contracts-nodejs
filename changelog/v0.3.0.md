# v0.3.0 Changelog

Status: historical release-train notes for the v0.3 contract update.

## Theme

OpHub Runtime, Capsule Events, and capability metadata foundations.

## Added

- `AgentMode` support for `embedded` and `ophub` registration paths.
- Manifest and report fields for service capabilities and event metadata.
- `ServiceKind` classification for OpHub-managed service inventory.
- Contract alignment for OpHub-managed multi-service reporting while preserving embedded SDK compatibility.

## Compatibility

- Pairs with Opstage CE `0.3.x`, Agent SDK `0.3.x`, OpHub Go v0.3 work, demo adapter mode, docs, and site.
- v0.3 metadata fields are additive and intended to be safe for older clients that ignore unknown manifest fields.
