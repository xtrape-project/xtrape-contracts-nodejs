# v0.5.0 Changelog Draft

Status: draft until the CE 0.1 release train is tagged and accepted.

## Theme

Xtrape CE 0.1 Phase 0 runtime contracts — frozen.

## Added

- Frozen Phase 0 schema surface: `CE_CONTRACT_VERSION` (`1`), `ServiceManifestSchema`,
  `ServiceInstanceSchema`, `AgentHeartbeatSchema`, `ConversationMessageSchema`,
  `ErrorModelSchema` (+ `CeErrorCode`). Sourced from `xtrape-docs`
  `runtime-platform/02..04` and `architecture/11`.
- Field/enum surface guard in `tests/ce-contracts.spec.ts`: any accidental removal,
  rename, or incompatible addition fails the suite (covers `.passthrough()` and
  optional fields that a parse-only test would miss).
- README `Contract Authority Boundary` and `Xtrape CE 0.1 Phase 0 Contracts` sections.

## Changed

- `repository` / `homepage` / `bugs` URLs point to the canonical Forgejo repository.

## Notes

- A contract change to any frozen schema/enum must bump `CE_CONTRACT_VERSION` and update
  the surface guard in the same change.
- npm name `@xtrape/capsule-contracts-node` remains a legacy physical compatibility
  identifier; `Capsule` is not a current concept.
- Pair with the CE 0.1 release train across `xtrape-server-ce`, `xtrape-agent-nodejs`,
  and `xtrape-demo`. Artifacts publish from `v*` tags only.
