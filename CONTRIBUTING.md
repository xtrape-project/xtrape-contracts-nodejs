# Contributing

This public repository receives reviewed source snapshots from private development.
Private development history is not mirrored.

Use this public repository's Issues for reproducible bugs and proposals. A public
build does not by itself change contribution or merge authority. Consult the
[public governance policies](https://xtrape.com/governance/) for the current
contribution process, and [SUPPORT.md](./SUPPORT.md) for support guidance.

Xtrape uses **Developer Certificate of Origin 1.1** sign-off (`git commit -s`).
Report what you actually tested, and disclose material AI assistance.
